# XR Adhesiolysis Trainer

A Unity-based prototype for training basic laparoscopic
adhesiolysis interaction.

## Current Version — Desktop MVP

The current prototype includes:

- Grasper movement and rotation
- Bowel grasping and release
- Tissue traction
- Dynamic adhesion stretching
- Visual feedback for traction force
- Maximum traction limitation
- Independent scissors control
- Basic adhesion cutting mechanics
